# 🧠 Plataforma Cognitiva NeoCórtex

Este projeto foi desenvolvido utilizando tecnologias fundamentais da Web, aplicando os conceitos estruturais, visuais e lógicos ministrados em sala de aula.

### 🛠️ Habilidades e Tecnologias Aplicadas:

- **HTML5 Semântico:** Estruturação organizada do conteúdo utilizando tags estruturais (<header>, <main>), tabelas de dados (<table>), formulários de captação (<form>) e listas ordenadas/não-ordenadas (<ul>, <ol>).
- **CSS3 Customizado:** Estilização centralizada em arquivo externo único (style.css), aplicando propriedades de Box Model (padding, margin, border), centralização de layouts e efeitos interativos de foco dinâmico (:hover).
- **JavaScript e DOM:** Programação lógica para manipulação dinâmica de elementos da página, controlando a alternância de visibilidade do menu hambúrguer (classList.toggle) e a transição de telas do questionário (style.display).
- **Persistência Local (Web Storage):** Utilização do recurso localStorage para salvar o nome do participante, pontuação e data de execução direto na memória do navegador.
- **Integração com APIs Externas:** Codificação de strings via método HTTP GET para compartilhamento de resultados de forma síncrona diretamente através do aplicativo do WhatsApp.
